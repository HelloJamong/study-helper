## Основные функции

- **Фоновое воспроизведение** — автоматическое воспроизведение лекций без вывода видео/звука
- **Загрузка видео** — сохранение видео лекций в формате mp4
- **Извлечение звука** — извлечение аудио из видео лекций в формате mp3
- **Speech to Text** — локальное преобразование речи в текст с помощью faster-whisper
- **AI-резюме** — резюмирование текста с помощью Gemini, OpenAI или OpenRouter API
- **Уведомления в Telegram** — уведомления о завершении воспроизведения, ошибках загрузки, завершении AI-резюме
- **Автоматический режим** — автоматическое воспроизведение, загрузка, резюмирование и уведомление о непросмотренных лекциях по заданному расписанию

## Установка и запуск

### 1. Скачать `docker-compose.yml`

Скачайте `docker-compose.yml` из [последнего релиза](https://github.com/HelloJamong/study-helper/releases/latest) или получите его следующей командой.

```bash
curl -O https://raw.githubusercontent.com/HelloJamong/study-helper/main/docker-compose.yml
```

### 2. Создать файл `.env`

Скачайте `.env.example` и переименуйте его в `.env`.

```bash
curl -L -o .env.example https://github.com/HelloJamong/study-helper/releases/latest/download/.env.example
mv .env.example .env
```

### 3. Загрузка образа и запуск

```bash
# Загрузка образа с Docker Hub (выполняется автоматически при первом запуске)
docker compose pull

# Запуск
docker compose run --rm study-helper
```

> Не используйте `docker compose up` — из-за мультиплексирования логов TUI ломается. Используйте только `run --rm`.

### 4. Начальная настройка

При первом запуске автоматически отображается экран настройки. При вводе студенческого номера/пароля они сохраняются в зашифрованном виде.

После настройки вы можете в любой момент изменить настройки, введя `setting` на экране списка курсов.

## Использование

При запуске выполняется автоматический вход в Learning X и отображается список курсов.

```
  #    과목명                  미시청 / 전체    학기
 ─────────────────────────────────────────────────
  1    소프트웨어공학            3 / 12        2025-1
  2    데이터베이스              0 / 10        2025-1
  3    운영체제                  5 / 15        2025-1

  과목 선택 (0: 종료 / setting: 설정 / auto: 자동 모드):
```

После выбора курса отображается список лекций по неделям. При выборе лекции появляется следующее меню:

```
  1. 재생
  2. 다운로드
  3. 취소
```

### Завершение

| Способ | Действие |
|------|------|
| Ввод `0` в списке курсов | Обычное завершение |
| `Ctrl + C` | Принудительное завершение |

## Путь загрузки

Загруженные файлы сохраняются по пути `data/downloads/` в директории проекта.

```
data/
└── downloads/
    ├── 과목명_강의명.mp4
    ├── 과목명_강의명.mp3
    ├── 과목명_강의명.txt
    └── 과목명_강의명_summarized.txt
```

## Пункты настройки

Доступ через ввод `setting` на экране списка курсов.

| Пункт | Описание |
|------|------|
| Формат загрузки | `video`(mp4) / `audio`(mp3) / `both`(mp4+mp3) |
| STT | Включение Whisper и размер модели |
| AI-резюме | Выбор Gemini / OpenAI / OpenRouter и настройка API-ключа |
| Уведомления в Telegram | Токен бота, Chat ID |

### Размер модели Whisper

faster-whisper использует INT8-квантование, поэтому размер файла модели примерно вдвое меньше по сравнению с openai-whisper.

| Модель | Размер (INT8) | Точность |
|------|------------|--------|
| tiny | ~39MB | Низкая |
| base | ~74MB | Средняя (по умолчанию) |
| small | ~122MB | Хорошая |
| medium | ~385MB | Высокая |
| large | ~750MB | Максимальная |

## Уведомления в Telegram

Вы можете получать уведомления о завершении воспроизведения, ошибках загрузки, результатах AI-резюме через Telegram.

Способ настройки см. в [руководстве по настройке Telegram](docs/telegram-setup.md).

## AI-резюме

Выберите Gemini, OpenAI или OpenRouter для автоматического резюмирования результатов STT. На экране настройки сначала выбирается агент, затем вводятся соответствующий API-ключ и модель.

| Агент | Особенности |
|----------|------|
| Gemini | Поддержка бесплатного тарифа, рекомендуется по умолчанию |
| OpenAI | Платный, выбор из списка моделей |
| OpenRouter | OpenAI-совместимый API с широким выбором моделей, часть моделей бесплатна (суффикс `:free`) — ID модели вводится вручную |

## Автоматический режим

![Автоматический режим](images/auto.png)

Введите `auto` на экране списка курсов, чтобы войти в автоматический режим.

Автоматический режим обрабатывает непросмотренные лекции по заданному расписанию (по умолчанию: KST 09:00 / 13:00 / 18:00 / 23:00).

```
재생(출석) → 다운로드 → STT 변환 → AI 요약 → 텔레그램 알림
```

Чтобы завершить автоматический режим, введите `0` + `Enter` на экране ожидания.

### Обязательные условия для автоматического режима

Для использования автоматического режима должны быть настроены все следующие пункты. При невыполнении вы будете перенаправлены на экран настройки.

| Пункт | Расположение настройки |
|------|-----------|
| Включение STT | Настройки → Преобразование текста (STT) |
| Включение AI-резюме + API-ключ | Настройки → AI-резюме |
| Включение уведомлений в Telegram + токен бота/Chat ID | Настройки → Уведомления в Telegram |

### Примечания

- **Не завершайте программу во время работы автоматического режима.** При принудительном завершении во время воспроизведения посещаемость может не засчитаться.
- Автоматический режим обрабатывает все непросмотренные лекции со статусом `completion != completed`. Лекции, уже просмотренные вручную, исключаются.
- Формат загрузки определяется настройкой `Правило загрузки`.
- Лекции, в которых произошла ошибка, пропускаются, а в Telegram отправляется уведомление об ошибке.
